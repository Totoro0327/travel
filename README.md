# 区域导览 + 美食地图融合版

本版按要求做了两项调整：

1. 将“区域导览地图”模块放到“景点介绍”和“美食攻略”下面，并与原“美食地图｜城市分区”融合成一个版块。
2. “美食攻略”改成按城市和美食类型分组，不再每个店铺单独平铺展示。

美食分组包括：
- 宁波：海鲜/本帮菜、面馆/小吃/点心、面包/甜品/冰淇淋、咖啡/茶饮、菜场/集市

- 台州市中心：台州美食

点击美食店名会跳转到融合后的区域导览地图，并定位到对应区域/点位。

- regions：9 个区域
